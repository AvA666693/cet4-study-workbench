# CET-4 学习工作台（手机适配版）

这是一个静态网页，无需构建或安装依赖。

## 本地打开
直接打开 `index.html` 即可。学习记录保存在当前浏览器的本地存储中。

## 发布成手机可访问的网址
将 `index.html` 上传到任意静态网站托管服务即可。若使用 GitHub Pages：
1. 在 GitHub 新建一个公开仓库。
2. 上传 `index.html` 到仓库根目录。
3. 打开仓库 Settings → Pages。
4. 在 Build and deployment 中选择 Deploy from a branch，分支选 `main`，目录选 `/(root)`，保存。
5. 等待发布后，打开 GitHub Pages 给出的网址即可在手机浏览器访问。

注意：数据保存在每台设备各自的浏览器里，不会自动跨设备同步。换手机前请在“数据管理”中导出备份，并在另一台设备导入。
