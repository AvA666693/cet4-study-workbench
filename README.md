# CET Study Lab V1.2 — 四级 / 六级备考网站

这是一个可以直接运行的个人试用版前端，采用原生 HTML/CSS/JavaScript，无需构建工具。网站以移动端优先、简洁可视化为设计原则。

## 快速预览

1. 解压整个文件夹。
2. 打开 `index.html` 即可使用核心前端功能。
3. 发布到 GitHub Pages 时，将文件夹中的内容上传至仓库发布目录，确保 `index.html` 位于发布目录根部。
4. GitHub Pages 只托管静态网站。账号、云同步和需要保密的 AI 调用必须接入服务端/托管后端。

## 本版已实现（V1.2）

- CET-4 / CET-6 级别切换。
- 听力和阅读原创示例题、答案判分与解析。
- 听力支持正常语速、慢速精听和停止播放；原文默认隐藏，由单独按钮控制显示/隐藏，避免听前直接看到文本；设备和浏览器支持情况可能不同。
- 听力/阅读题在提交答案后显示精选表达收藏入口，可将表达加入当前级别词汇复习。
- 当前听力声音由浏览器按文本合成，不是官方录音或真实考试音频；后续可在取得授权后接入音频文件。
- 写作和口语文本自查：词数、句子数、连接表达等规则提示；不等同于 AI 或官方评分。
- 词汇卡与简单间隔复习：再次学习安排次日、记住安排 3 天后、很熟悉安排 7 天后；复习间隔为简化规则，并非成熟的记忆算法。
- 每日 30 分钟建议路线包含词汇、听力、阅读、写作/口语轮换与错题回顾。
- 4 题短测原型、提交结果与解析；**不是正式全真模考**。
- 错题本、标记掌握、按记录计算正确率和技能分布、近 7 天记录可视化。
- 学习记录本地保存、JSON 导出/导入、清除本地数据。
- AI 后端接口调用入口；未配置后端时只提供本地规则建议，不声称已调用 AI。
- 账号/云同步状态透明提示：目前未实现，不显示假登录表单。

## 尚未实现 / 不能误认为已完成

- 没有真正的注册、登录、邮箱验证、密码重置、跨设备同步。
- 没有真正的生成式 AI，接口地址需要你部署后端后才会工作。
- 没有专业发音评分；浏览器语音识别不是所有环境都支持。
- 当前题量只是原创示例，题型覆盖不完整。真题选项只作为来源分类，**当前没有内置真题**。
- 模考只是一组客观题短测，不是按官方考试时长、题量和评分方式制作的全真模拟卷。
- 词汇间隔复习采用简单规则，不是经过验证的成熟记忆算法。
- 学习时长按完成的练习记录估算，每条记录约 5 分钟；它不是后台精确计时器。

## 项目结构

- `index.html`：可运行的前端原型。
- `data/question.schema.json`：题库数据结构规范与示例。
- `data/question-bank.sample.json`：小型原创题库示例，供后续独立维护。
- `docs/PRODUCT_SPEC.md`：产品规格、功能状态、开发阶段与验收标准。
- `docs/QUESTION_BANK_PLAN.md`：题库来源、版权、标签、审核与扩充计划。
- `docs/API_AND_COST.md`：后端 API 设计、AI 成本控制与阶段方案。
- `backend/supabase/schema.sql`：未来云端数据库初始结构草案（需要审查和部署，当前网站不会自动使用它）。
- `backend/.env.example`：服务端环境变量示例，不包含真实密钥。
- `legacy-prototype.html`：保留上一版原型，便于比较，不是网站入口。

## 建议开发顺序

1. 本地使用并检查练习、错题、词汇、导入导出。
2. 扩充并审核结构化题库，先不接入收费 AI。
3. 建立 Supabase 项目，执行数据库结构和 RLS 策略测试，再开发注册/登录与云同步。
4. 部署服务端 API，先做请求限流、日志脱敏、成本上限，再接 AI。
5. 完成完整模考、语音能力与无障碍测试后，再公开宣传完整功能。

## 题目来源说明

本项目样例题为原创教学内容。真实考试材料、官方音频、出版物题目及其解析须先核对使用授权和相关条款；不要把来源不明的题库上传到公开仓库，也不要将原创模拟题标记为真题。
